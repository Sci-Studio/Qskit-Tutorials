# Qskit-Tutorials
This repository is for python tutorials Qskit libraries for Quantum Computing using Python

# Run Project for first time
- Clone the repository 
```
git clone git@github.com:Sci-Studio/Qskit-Tutorials.git
```
- create virtual environment run 
```
python3 -m venv qiskit-env
source qiskit-env/bin/activate
```
- install requirements
```
pip install -r requirements.txt
```
- to test, run the notbook and check the `src/installation_test.ipynb`

# Checking Python virtual environement
- run the below commands, you should get the path of the newly created virtual environment
```
which python
which pip
python --version
pip --version
```
